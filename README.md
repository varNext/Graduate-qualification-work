# Дипломная работа бакалавра 

Тема ВКР: «Разработка программного модуля интеграции с системами маркетплейсов для нетиповой конфигурации 1С»

## Описание работы

Работа посвящена разработке python-модуля на базе фреймворка FastAPI для интеграции нетиповой конфигурации 1С с системой маркетплейса «Ozon» через REST API маркетплейса. В ходе разработки использован модульный подход с разделением логики на модули FBO и FBS. Архитектура разделена на четыре слоя:
 - API-слой — приём запросов от 1С
  - сервисный слой — бизнес-логика
  - трансформация — приведение данных к формату, понятному 1С
  - HTTP-клиент — взаимодействие с Ozon.

## Стек технологий 

- Язык: Python 3.10
- Backend: FastAPI, Pydantic, PyTest
- Интеграция: REST API Ozon
- Платформа-источник: 1С:Предприятие 8.3
- Инфраструктура: Docker
- Документация API: Swagger (OpenAPI)
